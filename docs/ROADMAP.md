# Roadmap

The current release implements the paid-round workflow and a public demo.
Later features need evidence and explicit release gates.

| Stage | Feature | Release gate |
| --- | --- | --- |
| Pilot | Real accounts and paid rounds | Database, email, provider tests, and country review |
| Pilot | Operator console | Restricted access and audited dispute decisions |
| Pilot | Tax invoices | Tax model and operator registration |
| Team | Team seats and permissions | Tenant membership tests and owner invitations |
| Team | Subscriptions | Billing events, fee entitlements, cancellation, and tax tests |
| Team | Calendar sync | Provider scopes, consent, and timezone tests |
| Team | ATS sync | Provider mapping and deletion controls |
| Scale | Pagination and exports | Load tests and data-access review |
| Scale | SSO and audit export | Tenant isolation and identity-provider tests |
| Scale | More currencies and countries | Provider approval and local pay policy |

## Product experiments

Measure round acceptance, completion, and time to transfer.
Ask candidates whether the terms and pay feel fair.
Compare employer budgets with completion and candidate feedback.
Test higher rates for specialist work and longer preparation time.
Do not lower an agreed amount after acceptance.

## Salary recovery

The plan excludes salary recovery until a separate legal and product review.
The candidate must never receive a hidden repayment obligation.
The bonus calculator remains a proposal until the owner approves a lawful contract and implementation.
